# 资源占用验证

2026-11-13，本机 Windows，1920×720，纯黑背景，粒子喷溅。浏览器使用相同视口和自动按键流程，对修改前后各采样 5 秒。下表新版指 v1.1.0，包含增强后的键帽照明，默认帧率上限由 60 调为 30。

| 场景 | 旧版绘制次数 | 新版绘制次数 | 旧版渲染器任务时间 | 新版渲染器任务时间 |
|---|---:|---:|---:|---:|
| 空闲 5 秒 | 250 | 0 | 104 ms | 4 ms |
| 单键长按 5 秒 | 251 | 124 | 277 ms | 168 ms |

绘制次数来自 `keyBloom.state.frameCount`。任务时间来自 Chromium DevTools Protocol `Performance.getMetrics` 的 `TaskDuration` 差值。当前测试环境的实际回调频率低于所设上限，因此这里报告实测次数，不把配置上限当成实测 FPS。

输入组件另作 15 秒采样：旧版进程累计 CPU 时间增加约 171.9 ms，新版在此次样本的计时精度下为 0 ms。新版仍有窗口存活检查、输入转发与诊断心跳，并不是完全不占用 CPU。

这些是一次短样本的计算工作量比较，不是整机电功率测量，也不能保证其他设备获得相同比例。屏幕亮度、GPU、驱动、后台应用和所选效果均会改变结果；液晶背光不会因为画面变黑而必然关闭。

v1.1.1 保留空闲停绘与持续动画限帧；新按键可提前绘制一帧。长按连发加快且溅射范围扩大，活跃时的绘制开销可能增加，未重新测量上表 CPU 时间。

## 已验证

- v1.1.1：15 FPS 设置下新按键在下一显示帧绘制，持续动画仍限帧；100 毫秒溅射半径超过 0.85 个键距，600 毫秒超过 2.3 个键距。以上为浏览器模拟时钟和画布像素检查，不是实体键到屏幕的端到端延迟测量。
- 八种模式的点按、长按、松开停止、系统重复按下去重、多键独立触发。
- 修饰键持续按住超过 15 秒、暂停恢复不补发大量事件、失焦/隐藏/清空/切换时停止。
- 玻璃长按累计、保持原裂纹、松开后延迟及完全修复。
- 空闲停止申请动画帧；按键和属性修改唤醒；看得见的动态背景持续刷新，亮度为 0 的动态背景停止绘制。
- 黑底按键中心照明增强，远离按键的区域仍为纯黑，照明滑块可关闭增强。
- 96 个动画事件上限、帧率与照明参数边界。
- Windows C# 组件构建、安装文件匹配、Lively WebView2 输入窗口发现和模拟 A 键自检；自检不改变系统前台窗口。
- 已有校准和自定义值保留，包括当前背景亮度；新字段只补默认值。

公开测试脚本使用与网页相同的源码。验证时通过 Playwright 请求拦截提供静态文件，不启动网络监听服务；无页面错误。

## 未验证

没有外接功耗仪测量；没有逐项复核所有实体键、组合键和 Fn 固件层；没有在另一台全新电脑完成安装测试。屏幕透过实际键帽后的亮度需要实物确认。

## v1.2.0 验证

当前默认值保留用户调节：60 FPS、黑底、照明 100。上面的 v1.1.0 性能数据不能作为 v1.2.0 的性能数据。

- 九种玩法通过同一套点按/长按、多键、暂停恢复与玻璃修复回归检查，无页面异常。
- 裂纹使用每次命中的随机种子，几何只在敲击时生成；每键保留最多八组，最早的裂纹保留，反复敲击不会无限增加内存。1000 次重复命中上限验证通过。
- 四种夹缝效果经过画布像素检查：键中心不被覆盖，沟渠可见；关闭后无其他动画时停绘。
- 音效开启可产生声音节点，关闭会停止全部节点并暂停音频上下文；本次未做人耳听感验收。
- 分类切换与活字印刷实际页面渲染通过。
- 默认值、实体校准、打包文件及公开 GitHub 文件一致性单独校验。

键盘屏在一次独立 DDC 关屏测试后离线，唤醒失败；该代码已移出产品，未安装、未打包或发布。这是 v1.2.0 发布时的状态；v1.3.0 改用下面的临时输出断开方案，不再使用该 DDC 代码。

## v1.3.0 验证（2026-11-14）

- 九种玩法、按下与长按、参数边界、随机碎裂、音效开关、空闲停绘和暂停回调回归通过，无页面错误。
- 四种轴间灯效铺满 1920×720 画布；字母键、空格、Enter、Shift 的轴区均为相同尺寸并位于原校准中心。像素检查覆盖轴区颜色、透明度、圆角、柔化、尺寸变化与屏幕边缘。软边图层只在几何或颜色参数改变时生成，每帧复用。
- 原生输入组件自检通过：丢失松键事件后释放、会话切换清理；用户确认退出微信/企业微信截图及锁屏解锁后均不再持续触发。安装后的 WebView2 启动参数含暂停回调开关。
- 单屏输出短测：临时断开 5 秒后恢复；软件比对其他两屏的分辨率、位置和刷新率保持不变；用户确认键盘屏恢复、其他屏正常。工作进程被终止时，独立守护恢复显示输出的软件检查通过。
- 休眠助手的 600000 毫秒阈值、禁用状态、原生结构大小、显示状态序列化往返检查通过。完整的键鼠闲置 10 分钟再操作唤醒周期尚待用户方便时验证。安全锁屏期间不修改显示拓扑。
- 安装保留已有自定义值与校准；新轴区参数补默认值。所有测试不代表真实键盘到屏幕延迟或电功率测量。

微信/企业微信截图过程中的静态覆盖层仍可能遮住动画，与退出后的按键残留是不同问题。v1.3.0 没有改动截图软件；不能声称截图遮罩已消除。上面的旧版 CPU 样本也不能视为当前新增光流与休眠助手的性能测量。
