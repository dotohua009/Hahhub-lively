# 键下生花 · IPI 84

基于 [Lively Wallpaper](https://github.com/lively-community/lively) 运行的开源互动壁纸。
[Lively 官方下载](https://github.com/lively-community/lively/releases)。本包仅含本项目，采用 GPL-3.0，完整许可见 LICENSE；Lively 来源见 THIRD_PARTY_NOTICES.md。

## 安装与后台联动

将壁纸 ZIP 拖入 Lively 图库，选择实际键盘屏。点“…”→“打开文件所在位置”，从导入后的壁纸库目录启动 KeyBloomInput.exe。导入 ZIP 本身不会自动运行这个组件。
要随登录启用，运行同目录 Enable-KeyboardInteraction.ps1；停止联动并取消登录启动，运行 Disable-KeyboardInteraction.ps1。更换副本前先关闭旧副本。
使用 Windows x64 与 Lively WebView2 网页播放器。Lively 输入转发设为“鼠标和键盘”。已在 Lively 2.2.1.0 验证。

## 效果与黑底照明

“…”→“自定义”：八种效果、六种背景。点按立即触发；长按约 180 毫秒后每 120 毫秒持续触发，多键可同时互动。玻璃沿原裂纹累积，按住时不修复，松开 1.6 秒后开始修复；像素植物最高八级。
粒子喷溅半径约为之前的两倍，扩散更快；新按键优先在下一显示帧绘制，持续动画仍遵守帧率上限。
默认白底。黑底请将背景亮度调为 0；“暗背景键帽照明”默认 85，调高可增加按键中心亮光，调为 0 可关闭。画面默认不显示提醒、注释或键名。
动画帧率默认 30，可调至 15–60。纯色背景没有动画时停止重绘；动态背景、游戏和玻璃修复时继续刷新。黑画面不等同于降低液晶背光功耗，实际效果需在设备上观察。
打地鼠按角色所在键；节奏接球使用 A/S/D/F/J/K/L，在光球落到圆环时按键。切换效果或重新加载会清空临时进度。

## 校准与隐私

默认 IPI 84：16u × 6 行，四边允许出界。换屏时开启校准线，用中心偏移和键距缩放让十字对准轴心，然后关闭辅助线。其他键盘布局需修改 layout.js。
组件仅向本目录对应的 Lively 播放器转发即时按下/松开状态，不转换文字、不保存按键历史、不使用网络。状态文件仅含连接状态、进程号及累计转发次数。
正常打字仍进入前台应用。Fn 是否独立上报由固件决定。未在另一台新电脑完整安装实测，未逐项验收全部实体键组合。
