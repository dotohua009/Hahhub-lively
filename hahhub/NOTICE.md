# 作者与许可

HAHHAN 为 hahhub 交互工坊及碎屏精简版的二次开发作者，并编写了黑洞的局部壁纸扭曲渲染。软件及本包自有交互内容使用 GPL-3.0，完整许可见 LICENSE。

固定 IPI 84 实体布局、校准数据、裂纹几何与 Windows 单屏合成方法改编自 dotohua009 的 [KeyBloom Lively](https://github.com/dotohua009/keybloom-lively)。保留原作者署名。

可选的 Lively 网页壁纸使用 [Lively Wallpaper](https://github.com/lively-community/lively) 的标准格式与属性回调。Lively 作者为 rocksdanister 及社区贡献者。工坊原生交互层独立运行。Wallpaper Engine 与元气壁纸由各自作者提供。
基础放射形网格由 [kossik/cracked-glass 0.4.0](https://github.com/kossik/cracked-glass/tree/8ff25f22ee22d20be67c31dc0e7efc0a475ef537) 离线生成，MIT 许可原文见效果包的 cracked-glass-LICENSE.txt。键位生长、复击保留、跨键路径和桌面绘制由工坊在本地执行。维护者可用 Node 22.15 或更高版本运行 tools/bake-glass.mjs，参数为解压后的 cracked-glass 0.4.0 npm 包目录。

Windows 包包含 Microsoft Edge WebView2 SDK 的 Core 程序集和 Loader。授权和第三方声明随 Windows 包提供，见 WebView2-LICENSE.txt 与 WebView2-NOTICE.txt。
