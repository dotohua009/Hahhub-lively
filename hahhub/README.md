# hahhub

hahhub 是面向透明屏键盘的 Windows x64 桌面程序。它在选定的扩展屏上叠加实体按键交互，可以让正在播放的视频或动态壁纸沿裂纹折射，也可以把附近的画面卷进黑洞。IPI 84 使用固定配列，每块键盘屏可分别校准。Fn 是否单独产生输入由键盘固件决定。

效果页的屏幕选择器左侧有一个鼠标边界按钮，只对识别到的 IPI 84 键盘屏显示。默认阻止光标进入这块扩展屏，点击可允许进入，再点恢复。偏好按设备保存，离线也可预设。主屏、镜像屏不启用限制。键位校准时可临时进入键盘屏，结束后自动恢复原设置。

在 Settings → Keyboard alignment 中，对照目标键盘屏的蓝色键帽框、白色虚线轴体和琥珀色轴芯调整。Layout 调整整张配列，三个边界可以分别平移和调整宽高。勾选 Adjust only this key 可微调单键，Save alignment 按所选显示器保存。独立 Lively 网页包沿用包内预设坐标。

效果库按画面内容分为「材质」（流麻、碎屏、泼墨、钻石切面）、「气象」（霜雾、风吹雪、冰刺）、「生物」（触须、蛛群）和「能量」（黑洞、方块连爆）。点击分类只浏览，点击效果才应用。视频上屏有独立入口。

每种效果都受当前帧率档的渲染预算约束。持续超出预算时，先减少并发键位或粒子数；降到最低细节后，帧间会留出休息时间。蛛群在省电、均衡、流畅、60 FPS 档最多分别有 96、204、312、420 只，结束后停止绘制。这些是软件工作量限制，实际整机功耗随硬件和背景内容变化。

「Glitter Flow / 流麻」将整张键盘作为一个约半满的透明流沙夹层。液流遇到轴体会分岔并在下游汇合。细粉与薄片随流转向，较重的薄片更快沉降，翻转时出现局部高光。近期按得更频繁的区域会吸引液体和亮片，换边敲击时液面带着惯性回流，停止输入约 3.2 秒后结束绘制。背景壁纸或视频可透过夹层看到。液面起伏时会映出附近壁纸或视频帧的颜色和亮部。薄片翻转时在青蓝、紫红与暖金间变色，较大的亮片掠过光源时闪出四角星芒。背景反射最多每秒取样 12 次，无可用画面时液面仍保留珠光。[LiquidFun 分层液面示例](https://github.com/google/liquidfun/blob/master/liquidfun/Box2D/EyeCandy/engine.cpp) · [three.js 薄片法线示例](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/textures/FlakesTexture.js)

本地效果库中的「Frost Lance / 冰刺」先在键帽边缘的几个随机位置冒出冰芽。长按时，新冰簇陆续向外长出，主刺、细枝和簇间空隙大小各异。「Tendrils / 触须」沿校准后的键帽外沿伸出多条粗细不同的触手，部分末梢会追向邻键，可设置本体颜色或启用五彩渐变。「Silk Colony / 蛛群」轻按从键帽上的落点抽出主丝，长按逐圈织出横丝，蜘蛛沿校准后的键缝聚来；颜色在本效果内设置。

「气象 / Weather」收录霜雾、风吹雪和冰刺。冷雾从整块键帽表面向四周扩散，空格键两端与中段会同时起雾，长按会在键帽上形成大小不一的冰晶和霜斑，敲邻键会推开已有雾团。风吹雪绕过键帽，在背风处沉积，沿相邻键扫过可扬起积雪。霜雾和风吹雪分别保存浓度、扩散范围和消散时间，可在效果页直接按键预览。

「Voxel Fuse / 方块连爆」按键放下方块，可在该效果面板调整引信（0.15–5.00 秒，默认 1.20 秒）。改动自动保存，从下一枚方块生效。邻近的方块遇到冲击波会提前引爆。「Prism / 钻石切面」长按时沿键帽、轴体和轴芯的校准轮廓折射底图，松手后收起。两项均可在效果库直接应用到所选键盘屏。

泼墨和黑洞的面板各有独立的「Enhanced preset / 升级版」开关，默认关闭。泼墨增加双色笔触，黑洞增加吸积盘亮带。

「Ink Splash / 泼墨」会在按下的键位溅出彩墨。每次生成约 108 至 305 颗飞滴，混合四种泼洒形态。多数飞滴碰到当前键帽边缘后减速反弹，少数会溅到旁边。墨色会在轴心短暂附着，同键复击可叠色，长按可持续喷射，松手后恢复。喷射范围可调为 75%–250%（默认 160%），恢复时间可调为 0.5–6 秒（默认 3.5 秒）。泼墨可以叠在壁纸或上屏视频之上。

碎裂和黑洞各有独立的「Edge glow / 边缘辉光」。点击色块选色并确定，即可保存到该效果，预览和目标屏同步生效。颜色沿裂纹或洞口边缘发光，玻璃和洞口周围仍取用背景原色。

按下时从校准轴心起裂，初始接触直径为轴宽的一半（1920 像素宽基准下为 39.5 像素）。默认「Wide」使用较少的主裂缝形成大片玻璃。「Fine」增加细密分支。长按令裂尖持续推进，松手后停留指定时长，再沿原路收回。愈合延迟可设为 0 至 5 秒，默认 0.8 秒，与愈合时间分别保存。愈合前复击会沿原纹继续生长；相继按下的键会从邻近的已裂边缘引出连接路径。扩散范围和密度在每处新损伤开始时生效。

「黑洞 · IPI 84」使用同一份键位校准。点击效果库里的「Black Hole」，已启用的目标屏会切换交互效果。按键让该位置的壁纸纹理旋入不规则暗核，外围纹理沿螺旋加速向内流动，洞口轮廓在近圆和椭圆之间缓慢流动，短按时撕扯范围直径约为三个标准键距。长按约 4.7 秒，黑洞会从按键向最远的角扩张，吞没整块目标屏。相邻键在约 0.36 秒内合并，远键可分别触发。松手后收拢。吸入强度通过「Save」单独保存。独立 Lively 包对包内背景施加扭曲；第三方动态壁纸的实时互动使用工坊桌面模式。

效果库共用 16、24、30、60 FPS 四档上限，实际帧率取决于屏幕刷新、壁纸采样和渲染耗时。

## 安装与使用

解压 Windows 软件包后运行 `powershell -ExecutionPolicy Bypass -File .\install.ps1`，再打开桌面「hahhub」。点击右上角的显示器名称，选中目标后点「Enable effects」。已启用时，选另一屏并点「Use this display」可以移过去。点击「Pause effects」关闭所选交互层。

界面默认英文。在 Settings → Language 中选择 English 或简体中文即可切换。界面和托盘菜单随即更新，重启后保留所选语言。

打开 Settings → Updates 会在线检查版本，也可点击 Check now。发现新版时点击 Update and restart，工坊会校验下载包并在当前用户目录内更新。更新过程中保留键位、屏幕、语言和效果设置。

工坊按 Windows 显示器设备路径保存目标。显示器编号改变会跟随同一设备；断开时等待，原设备重新连接后恢复。复制模式中的显示器共用画面，切到扩展模式后才可单独启用。更换接口导致 Windows 生成新设备路径时，可重新选择。首次安装需要自己选屏，旧版用户升级会尽可能保留原键盘屏的选择。

背景继续由原壁纸软件管理。独立交互层只绘制在选中的桌面上，可点击穿透。对于能提供实时画面的桌面壁纸播放窗口，玻璃碎片会局部折射壁纸当前帧，并按碎片朝向映出周围画面和光色。对于直接输出到桌面的 DX11 场景，工坊只读取露出的桌面区域，并将自身排除在屏幕捕获之外。普通窗口挡住取样点或画面不可用时保留裂纹。播放窗口取样和局部绘制仅在碎裂期间运行。普通应用窗口在它上方。裂纹和功耗设置保存在当前用户的交互工坊数据目录，愈合后停止绘制。原生模式可独立使用。另附的网页 ZIP 可自行导入 Lively，以独立壁纸形式使用其自定义面板。

侧栏作者区的「GitHub」打开 [hahhub](https://github.com/dotohua009/Hahhub-lively)。点击「Settings」可查看 HAHHAN 的微信捐赠二维码，按 Esc 或点击「Back to effects」即可关闭。

「Video Cast」可将 B 站 BV／av 播放页或 MP4、WebM、M4V 直链在选定的扩展屏全屏播放。粘贴链接后按 Enter 或点击「Cast video」。默认按屏幕实际像素等比铺满；取消「Fill screen (crop edges)」可保留完整画幅。B 站使用官方站外播放器。目标屏隐藏播放控件，在工坊面板可暂停、继续、切换静音或停止。播完或停止上屏后会释放播放窗口。播放器需要 Microsoft Edge WebView2 Runtime。

工坊和上屏窗口均从 Alt+Tab 和任务栏隐藏。最小化或点击 × 会收起控制面板，视频和按键交互继续运行。双击系统托盘的 H 图标或再次打开桌面快捷方式可恢复面板。右键托盘图标，选择「Quit hahhub」可结束本次播放和后台交互。安装后，下次登录 Windows 会自动托管到托盘。

设置中的「Use third-party wallpapers」默认开启，可保存开关。上屏时工坊暂停第三方壁纸取样。已启用的交互效果沿用原有键位和参数，在目标屏的视频画面上生效。无按键效果时停止取样和绘制。停止或播完后恢复之前的交互目标屏和壁纸取样设置。壁纸软件自身的后台播放策略由该软件控制。

## 构建与移除

源码根目录运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`。编译使用 Windows 自带 .NET Framework 4.8 x64 与 WPF。release 目录是可安装的程序与自有交互包。独立的 Lively ZIP 提供网页预览和 Lively 输入。

卸载时先暂停交互，退出工坊并运行 `"HAHHAN Studio.exe" --stop-host`，再移除桌面与启动目录里的 hahhub 快捷方式及当前用户 LocalAppData 下的 HAHHAN/Interaction Studio。可在 Lively 单独管理已导入的网页壁纸。
